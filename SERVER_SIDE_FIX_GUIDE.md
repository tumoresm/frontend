Missing Route Definition\n\n**Problem**: The `/users/profile/update` endpoint is not defined in your FastAPI server.\n\n**Solution**: Add the route to your FastAPI server. Here's what you need:\n\n```python\n# In your main FastAPI file (e.g., main.py or app.py)\nfrom fastapi import FastAPI, HTTPException, Depends\nfrom pydantic import BaseModel\nfrom typing import Optional\n\napp = FastAPI()\n\n# Request model for profile update\nclass ProfileUpdateRequest(BaseModel):\n    userId: str\n    address: str\n    idDocumentUrl: str\n    role: str\n    verificationStatus: str\n    profileImageUrl: Optional[str] = None\n\n# Profile update endpoint\n@app.put(\"/users/profile/update\")\nasync def update_user_profile(profile_data: ProfileUpdateRequest):\n    try {\n        # Your profile update logic here\n        # This should update the user document in Appwrite\n        \n        # Example response\n        return {\n            \"message\": \"Profile updated successfully\",\n            \"userId\": profile_data.userId,\n            \"status\": \"success\"\n        }\n    except Exception as e:\n        raise HTTPException(status_code=500, detail=str(e))\n\n# Health check endpoint (recommended)\n@app.get(\"/health\")\nasync def health_check():\n    return {\"status\": \"healthy\", \"service\": \"FieldForce API\"}\n\n# Root endpoint\n@app.get(\"/\")\nasync def root():\n    return {\"message\": \"FieldForce FastAPI Server\", \"version\": \"1.0.0\"}\n```\n\n### 2. Incorrect Route Path\n\n**Problem**: The route might be defined with a different path.\n\n**Check your server for these variations**:\n- `/user/profile/update` (singular \"user\")\n- `/api/users/profile/update` (with \"/api\" prefix)\n- `/v1/users/profile/update` (with version prefix)\n- `/users/profile` (without \"/update\")\n- `/profile/update` (without \"/users\")\n\n**Solution**: Either update your server route to match `/users/profile/update` or update the client endpoint.\n\n### 3. Wrong HTTP Method\n\n**Problem**: The endpoint exists but expects a different HTTP method.\n\n**Check if your server has**:\n- `@app.post(\"/users/profile/update\")` instead of `@app.put(...)`\n- `@app.patch(\"/users/profile/update\")` instead of `@app.put(...)`\n\n**Solution**: Either change the server method to PUT or update the client to use the correct method.\n\n### 4. Router Configuration Issues\n\n**Problem**: The route is defined in a separate router that's not properly included.\n\n**Solution**: If you're using APIRouter, make sure it's included:\n\n```python\nfrom fastapi import APIRouter\n\n# In a separate file (e.g., users.py)\nusers_router = APIRouter(prefix=\"/users\", tags=[\"users\"])\n\n@users_router.put(\"/profile/update\")\nasync def update_profile(profile_data: ProfileUpdateRequest):\n    # Your logic here\n    pass\n\n# In your main app file\nfrom .users import users_router\n\napp = FastAPI()\napp.include_router(users_router)  # Make sure this line exists\n```\n\n### 5. CORS Configuration\n\n**Problem**: CORS might be blocking the request.\n\n**Solution**: Add CORS middleware:\n\n```python\nfrom fastapi.middleware.cors import CORSMiddleware\n\napp = FastAPI()\n\n# Add CORS middleware\napp.add_middleware(\n    CORSMiddleware,\n    allow_origins=[\"*\"],  # In production, specify your Flutter app's origin\n    allow_credentials=True,\n    allow_methods=[\"*\"],\n    allow_headers=[\"*\"],\n)\n```\n\n## Debugging Steps\n\n### 1. Check Available Routes\n\nAdd this endpoint to see all available routes:\n\n```python\n@app.get(\"/debug/routes\")\nasync def list_routes():\n    routes = []\n    for route in app.routes:\n        if hasattr(route, 'methods') and hasattr(route, 'path'):\n            routes.append({\n                \"path\": route.path,\n                \"methods\": list(route.methods)\n            })\n    return {\"routes\": routes}\n```\n\nThen visit: `http://192.168.100.5:8000/debug/routes`\n\n### 2. Add Request Logging\n\nAdd middleware to log all incoming requests:\n\n```python\nfrom fastapi import Request\nimport time\n\n@app.middleware(\"http\")\nasync def log_requests(request: Request, call_next):\n    start_time = time.time()\n    print(f\"Incoming request: {request.method} {request.url}\")\n    print(f\"Headers: {dict(request.headers)}\")\n    \n    response = await call_next(request)\n    \n    process_time = time.time() - start_time\n    print(f\"Response status: {response.status_code}\")\n    print(f\"Process time: {process_time:.4f}s\")\n    \n    return response\n```\n\n### 3.
